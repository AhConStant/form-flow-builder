# 计算式 / 条件隐藏 / 流水号（平台实测）

移动视图里能带「公式」的地方只有三个，全部以**字符串**形式存在，表达式按字段**显示名（label）**解析，不认数据库字段编码。
本文件是 2026-11-22 从平台设计器导出件（`3333(移动视图).txt`）实测归纳的结果，生成器已按此实现。

## 一、引用语法

| 写法 | 含义 |
|---|---|
| `[tableKey\字段名]` | 取同表该字段的显示值 |
| `[tableKey\字段名(值)]` | 取该字段的**选项值**（单选/多选用它判断，不用 label） |
| `[tableKey\子表名\列名]` | 取重复表某列（子表名 = 重复表字段的 label） |

> 反斜杠 `\` 是平台分隔符，不是转义；JSON 里要写成 `\\`。
> 多个引用拼在一起时用中括号包住整体也可以，如 `('[tableKey\经费来源(值)]').indexOf('其他')`。

## 二、spec 里怎么写（生成器负责转换）

spec 只写 `{字段名}` 占位，生成器转成上表写法：

```json
{ "label": "天数", "type": "input", "calc": "datediff({开始时间},{结束时间})+1" }
{ "label": "金额", "type": "inputNum", "calc": "{单价}*{数量}" }
{ "label": "合计金额", "type": "inputNum", "calc": "sum({费用明细\\金额})" }
```

- `calc` → 属性 `autoCalc`，**只有 `input` / `inputNum` / `inputNumDisplay` 能带**，其他类型生成器直接报错。
- 重复表列内的 `calc`：`{列名}` 自动补成 `[tableKey\表名\列名]`。
- 表达式里已经写了 `[tableKey\...]` 原文时**原样保留**，不再做替换（想手写平台原文也可以）。

## 三、常用算式

| 场景 | 表达式 | 说明 |
|---|---|---|
| 天数（含头含尾） | `datediff([tableKey\开始时间],[tableKey\结束时间])+1` | `datediff` 返回天数差，`+1` 才是含首尾 |
| 子表某列合计 | `sum([tableKey\重复表\金额])` | 子表名 + 列名 |
| 行内相乘 | `[tableKey\单价]*[tableKey\数量]` | 主表字段 |
| 子表行内相乘 | `[tableKey\重复表\单价]*[tableKey\重复表\数量]` | 列级 `calc` 用 |
| 数字格式取值 | `join([tableKey\总价])` | `inputNumDisplay` 的取值方式，固定用 `join()` |

## 四、金额大小写（`inputNumDisplay`）

`displayFormat` 只有三个实测取值：

| 值 | 含义 |
|---|---|
| `"￥"` | 小写金额（带币符） |
| `"RMB"` | 大写金额（人民币中文大写） |
| `""` | 普通数字格式 |

两个控件都靠 `autoCalc: "join([tableKey\总价])"` 取值，**成对出现**：源表有「总价小写 / 总价大写」就各建一个。
`inputNumDisplay` 一律 `isRequire: false`（计算展示，不让人填）。

## 五、条件隐藏（`hideFormula`）

值是 **JS 表达式字符串**，为 `true` 时隐藏该控件；同时字段初始态必须 `isHidden: true`（先藏，条件满足才显）。

| 场景 | 表达式 |
|---|---|
| 单选 ≠ 某值才显示 | `[tableKey\是否市内(值)]!='是'` |
| 多选**不含**某项才显示 | ` ('[tableKey\经费来源(值)]').indexOf('其他')==-1` |

- 单选/多选判断**必须带 `(值)`**，否则拿到的是显示名而不是选项值。
- 平台保存的原串里，`indexOf` 那条前面**有一个空格**，属平台原样输出，不必删。
- 连带规则：被隐藏的字段通常 `isRequire: false`（不填也能提交），生成器不自动改，写在 spec 里。

## 六、流水号（`sn`）

```json
{ "label": "编号", "type": "sn", "snFormula": "[Date:YY]-[NO:____]" }
```

| 属性 | 说明 |
|---|---|
| `snFormula` | 编号格式：`[Date:YY]` 两位年份、`[NO:____]` 流水位数（下划线个数 = 补零位数） |
| `snMode` | **必须等于该元素自己的 `id`**，平台靠它把格式与控件对上；写错编号不生效（校验器会拦） |

`sn` 是只读展示，`isRequire: false`；不带 `autoCalc` / `hideFormula`。

## 七、落库后长什么样（别被吓到）

平台回写会把 `properties` 全部按**字母序**重排，并按需补键：

- 普通 66 键；带 `calc` 的 67 键（+`autoCalc`）；同时带隐藏的 68 键（+`hideFormula`）；
- `sn` 68 键（66 + `snFormula` + `snMode`）；`inputNumDisplay` 67 键（66 + `autoCalc`）；
- 顶层多一个可选键 `bindData`（= 已绑字段编码，如 `KM0014`），位置在 `type` 之后。

生成器已按字母序写键，校验器允许上述可选键，遇到平台回写件同样能过。
